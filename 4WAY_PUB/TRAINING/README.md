# Separate Training Material

This directory is separate from `AUTISM/`. Its contents are not evidence for
the autism paper and must not be presented as a prevention, treatment, or
causal explanation for ASD.

Included source material:

- `iPAP Beginner Program SUMMARY.pdf`
- `iPAP Beginner Program SUMMARY.pdf.txt`

The PDF is the source object. The text file is a reading copy. They are shipped
together for provenance and accessibility.
