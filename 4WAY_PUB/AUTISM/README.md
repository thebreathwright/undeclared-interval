# Autism Paper Set

This directory contains the publication rewrite:

- `AUTISM_PAPER_REWRITE.v1.md`

It is a self-contained evidence-bound rewrite of the reviewed breast-pump and
autism paper. It retains the research questions about feeding mechanics,
coordination, energy burden, sleep, airway health, and ASD measurement. It does
not carry forward a causal claim, a training method, a product protocol, or
commercial material.

The source review was retained outside this public autism-paper set because it
contains material that is not part of this rewrite. Source SHA-256:
`51f4dd16386afbe539e71d0e3cc9691931a75f23f36161657a9f53bcb48f1513`.
